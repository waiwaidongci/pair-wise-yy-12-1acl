# 马术蹄铁修整档案

面向马术俱乐部蹄铁师的日常修蹄记录工具：马匹档案 → 左前/右前/左后/右后四蹄检查 →
蹄况变化对比 → 蹄铁更换历史 → 下次复查提醒，全部数据保存在当前浏览器，无需后端。

## 功能流程

1. **马匹档案**：编号（唯一）、马名、用途（运动马/休养马/教学马）、品种、备注；
   支持搜索与按用途/复查/异常步态筛选。
2. **四蹄检查**：一次检查逐蹄记录蹄形评估、蹄铁类型、磨耗、钉位、备注，
   可勾选「异常步态」并填写步态说明；支持添加照片（自动压缩后存入浏览器）。
3. **蹄况变化**：提交检查后立即展开与上次检查的逐蹄对比，
   标注好转/恶化、新发/持续/消失的异常步态；首次检查建立四蹄基线。
4. **蹄铁更换**：可登记四蹄整体或单蹄更换，记录原蹄铁→新蹄铁、原因、钉位、备注，
   与检查记录合并在同一时间线倒序展示，可追溯、可删除。
5. **复查提醒**：检查时填写下次复查日期，工作台自动汇总近 14 天日程，
   逾期/今天到期高亮。
6. **备份导入导出**：一键导出 JSON 完整备份；导入旧备份时，与现有马匹同编号的马
   逐匹选择「保留现有记录」（跳过该马全部备份内容）或「并入历史」
   （档案以现有为准，备份的检查/换蹄追加并自动去重）。

## 数据安全

- 所有数据通过 **localStorage 只追加事件日志** 保存：提交时先同步写日志、
  再更新界面，意外关页或刷新后重开自动重放恢复，已提交内容不丢。
- 日志累积 100 条自动压缩为快照；空间不足时优先保住文字记录，照片单独提示。
- 检查/换蹄表单内容**自动暂存为草稿**（防抖写入），关页后重开可恢复或放弃。
- 清理浏览器数据前请先「导出备份」。

## 技术栈

React 19 + Vite + TypeScript（无额外运行时依赖）

## 本地运行

```bash
npm install
npm run dev      # 开发，端口 62011
npm run build    # 类型检查通过后产物构建到 dist/
```

冒烟验证（Node 模拟 localStorage，覆盖日志落盘、重放恢复、压缩、空间不足、
导入冲突选择与去重）：

```bash
node scripts/smoke.cjs
node scripts/smoke-import.cjs
```
