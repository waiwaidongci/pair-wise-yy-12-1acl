# hxyfront-62011 马术蹄铁修整档案

面向马术俱乐部蹄铁师的每日修蹄记录工具：把 **马匹档案 → 左右前后四蹄检查 → 蹄铁更换 → 复查提醒** 连成一套可操作流程。

## 功能流程

1. **马匹档案**：编号（唯一）、马名、品种、状态（运动马/休养马/调教马）、负责人、长期备注。
2. **每日检查记录**：
   - 左前 / 右前 / 左后 / 右后四蹄分别登记蹄形、均衡度、异常问题（磨耗不均、裂纹等）和备注；
   - 步态检查并可一键标记异常步态；
   - **检查过程中即时与该马上次记录对比**：新增问题（红）、消除问题（绿）、蹄形变化、步态变化当场显示，卡片高亮。
3. **蹄铁更换**：任一蹄可独立登记「旧蹄铁 → 新蹄铁、钉位、更换原因」，自动带入该蹄当前在穿的蹄铁；提交后进入**可追溯的换蹄历史**，时间线可展开查看每次更换。
4. **复查提醒**：下次复查日期（支持 +7/+14/+30 天快捷填写）；首页集中显示逾期、今天、3 天内到期的马，列表带逾期天数徽标。
5. **照片备注**：蹄部照片自动压缩后随记录保存在本机。

## 数据与安全

- **数据只存在当前浏览器**（localStorage），不联网、不上传。
- **提交即落盘**：所有新增/修改/删除在点击提交的瞬间同步写入浏览器存储，提交成功后即使意外关页、断电，已提交内容也不会丢。
- **草稿保护**：正在填写的检查表单每 0.5 秒自动存为草稿；意外关页后再次打开该马的新记录表单，可选择恢复或丢弃；有未提交内容时关页会二次确认。
- **备份导出 / 导入**：一键导出 JSON 备份。导入旧备份时：
  - 编号不存在的马 → 直接作为新马加入；
  - **同一匹马已有资料时逐匹让蹄铁师选择「并入历史」（备份记录按时间追加、自动去重）或「保留现有记录」（跳过该马）**，导入前有完整预览。
- 存储数据意外损坏时不会误删，会自动另存为 `.corrupt` 文件后以空库启动。
